# Dairy Flat Airline Booking System

This is my 159.352 assignment 2 project. It is a simple online booking system designed for a fictional airline that operates at Dairy Flat Airport.

Live site: https://dairy-flat-airline.vercel.app  
GitHub: https://github.com/a15634962227-png/dairy-flat-airline

## Features

- Search scheduled flights by route, date range, and passenger count
- Create a booking for an available flight
- Show an invoice after booking
- Search and manage a booking by booking reference
- Cancel a booking
- Search all bookings for a passenger by email

## Tech used

- Next.js
- TypeScript
- MongoDB Atlas
- Tailwind CSS
- Vercel
